# Movie-recommender

> 20211423 서해승  
> C++ 프로그래밍 및 실습 마일스톤 과정을 위한 레포지토리입니다.

## 프로젝트 개요

영화, 사용자, 평점 데이터를 관리하고 사용자 기반 협업 필터링 방식으로 영화를 추천하는 콘솔 프로그램입니다.

프로그램은 실행 시 `data/*.csv` 파일을 읽어오고, 종료 시 현재 데이터를 다시 CSV 파일에 저장합니다.

## 폴더 구조

```text
movie-recommender/
├── data/
├── include/
├── obj/
├── src/
├── Makefile
└── README.md
```

- `data/`: 영화, 사용자, 평점 CSV 파일 저장
- `include/`: 헤더 파일 저장
- `src/`: 클래스 구현 파일 저장
- `obj/`: 컴파일된 오브젝트 파일 저장
- `Makefile`: 빌드와 실행 명령 정의

## 현재 파일별 용도

1. `Movie`, `User`, `Rating`
- 영화, 사용자, 평점 데이터를 표현하는 기본 클래스입니다.

2. `MovieManager`, `UserManager`, `RatingManager`
- 각 데이터 목록을 `vector`로 관리합니다.
- 추가, 검색, 목록 출력, CSV `loadFromFile` / `saveToFile` 기능을 담당합니다.
- `BaseManager`를 상속하여 공통 인터페이스를 맞춥니다.

3. `Manager`
- 세부 Manager들을 조율하는 상위 클래스입니다.
- 중복 ID, 존재하지 않는 사용자/영화, 평점 범위, 추천 가능 여부 같은 도메인 검증을 담당합니다.
- 프로그램 시작 시 CSV를 로드하고 종료 시 저장합니다.

4. `UserInterface`
- 메뉴 출력과 사용자 입력을 담당합니다.
- 정수/실수 입력 형식 검증을 수행하고, 실제 작업은 `Manager`에 요청합니다.

5. `SimilarityCalculator`
- 두 사용자의 평점 목록을 비교하여 유사도 점수를 계산합니다.
- 공통 영화 수와 평점 차이를 기반으로 계산합니다.

6. `Recommender`
- 대상 사용자와 유사한 사용자를 찾고, 대상 사용자가 아직 보지 않은 영화를 추천합니다.
- 추천 결과는 movieId 목록으로 반환합니다.

7. `Constants`
- 평점 범위, 개봉연도 범위, 추천 기준값처럼 코드 전체에서 같이 쓰는 상수를 모아둔 파일입니다.

## 실행방법

```zsh

make

# 프로그램 실행

# 빌드 결과물 삭제
make clean
```

직접 실행하는 경우에는 프로젝트 루트에서 실행해야 합니다.

```zsh

```

## 메뉴 기능

```text
1. 영화 추가
2. 제목으로 검색
3. 전체 목록 출력
4. 평점순 정렬 출력
5. 사용자 추가
6. 사용자 목록 출력
7. 평점 입력
8. 영화별 평점 보기
9. 영화 추천 받기
10. 메뉴 다시 보기
0. 종료
```

## CSV 데이터 형식

1. `data/movies.csv`

```csv
id,title,genre,year
1,Inception,Sci-Fi,2010
```

2. `data/users.csv`

```csv
id,name,email
101,Alice,alice@example.com
```

3. `data/ratings.csv`

```csv
userId,movieId,score
101,1,4.5
```

평균 평점은 CSV에 따로 저장하지 않습니다. 프로그램 시작 시 `ratings.csv`의 개별 평점을 읽고, `Manager`에서 영화별 평균 평점을 다시 계산합니다.

## 추천 알고리즘 흐름

1. 추천받을 사용자의 평점 목록을 찾습니다.
2. 사용자가 이미 본 영화 id를 저장합니다.
3. 다른 사용자들과의 유사도를 계산합니다.
4. 유사도가 높은 사용자를 기준으로 후보 영화를 찾습니다.
5. 대상 사용자가 이미 본 영화는 제외합니다.
6. 너무 낮게 평가된 영화는 추천 후보에서 제외합니다.
7. 추천 점수를 기준으로 정렬한 뒤 상위 영화 id를 반환합니다.

유사도 계산은 공통으로 평가한 영화 수와 평점 차이를 기준으로 합니다.

```text
similarity = 공통 영화 수 * 가중치 - 평점 차이 합
```

공통 영화가 없는 경우에는 추천 근거가 부족하다고 보고 낮은 유사도 값을 반환합니다.

## 예외 처리와 검증

- CSV 파일을 열 수 없으면 파일별로 로드 실패 메시지를 출력합니다.
- CSV 한 줄에 문제가 있으면 프로그램을 종료하지 않고 해당 줄만 건너뜁니다.
- 영화 개봉연도는 허용 범위를 벗어나면 등록하지 않습니다.
- 평점은 `0.0` 이상 `5.0` 이하만 허용합니다.
- 존재하지 않는 영화나 사용자에 대해서는 등록/추천을 진행하지 않습니다.
